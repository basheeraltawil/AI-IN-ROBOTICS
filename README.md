## 📖 نظرة عامة | Overview

دليل شامل وتفاعلي عن الذكاء الاصطناعي في الروبوتات، يغطي الأساسيات النظرية والتطبيقات العملية. هذا المشروع مصمم لتعليم المهندسين والطلاب والمتحمسين كيفية دمج تقنيات الذكاء الاصطناعي في الأنظمة الروبوتية.

A comprehensive and interactive guide to Artificial Intelligence in Robotics, covering theoretical foundations and practical applications. This project is designed to teach engineers, students, and enthusiasts how to integrate AI technologies into robotic systems.

## ✨ الميزات الرئيسية | Key Features

### 🎯 محتوى شامل | Comprehensive Content
- **الأساسيات النظرية**: مفاهيم الذكاء الاصطناعي في الروبوتات
- **التطبيقات العملية**: أمثلة حقيقية ودراسات حالة
- **المفاهيم المتقدمة**: الشبكات العصبية، التعلم المعزز، الرؤية الحاسوبية
- **المستقبل والابتكارات**: الاتجاهات المستقبلية والتقنيات الناشئة

### 🛠️ تقنيات مغطاة | Covered Technologies
- **البرمجة**: Python, ROS, C++
- **مكتبات الذكاء الاصطناعي**: TensorFlow, PyTorch, OpenCV
- **الروبوتات**: Industrial Robots, Service Robots, Autonomous Vehicles
- **الخوارزميات**: Neural Networks, Reinforcement Learning, Computer Vision

### 🎨 تصميم تفاعلي | Interactive Design
- واجهة مستخدم عصرية ومتجاوبة
- رسوم بيانية تفاعلية وشبكات عصبية متحركة
- دعم المظاهر الفاتحة والداكنة
- تصميم متوافق مع الهواتف الذكية

## 🚀 البدء السريع | Quick Start

### المتطلبات | Prerequisites
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت لتحميل الخطوط والأيقونات الخارجية

### التشغيل المحلي | Local Development
```bash
# استنساخ المستودع
git clone https://github.com/basheeraltawil/AI-IN-ROBOTICS.git

# الانتقال إلى مجلد المشروع
cd AI-IN-ROBOTICS

# تشغيل خادم محلي
python -m http.server 8000

# أو باستخدام Node.js
npx serve .

# زيارة الموقع
# افتح http://localhost:8000 في المتصفح
```
